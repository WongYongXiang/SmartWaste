# ♻️ AI-ENABLED SMART WASTE MANAGEMENT SYSTEM


## 📖 About This Project
By 2035, Singapore’s only landfill, Pulau Semakau, is projected to reach its maximum capacity. A major contributing factor is the high contamination rate of public recyclables due to improper sorting, as well as the carbon emissions generated by inefficient, static waste collection routes.

This project is a **Dual-Approach Ecosystem** designed to solve both problems:
1. **For the Consumer:** A mobile application featuring on-device AI that instantly identifies waste and guides users on proper disposal methods, backed by a gamified rewards system to build long-term sustainable habits.
2. **For the Waste Fleet/Companies:** A conceptual management dashboard that utilizes "nearest-neighbour" route optimization to ensure trucks only visit bins that are critically full, drastically reducing fuel consumption and operational carbon emissions.

## ✨ Key Features
* **Frictionless AI Scanner:** Real-time, offline waste classification using PyTorch Mobile. Camera feeds are processed entirely on-device, ensuring zero latency and total user privacy.
* **Gamification & Rewards:** Users earn points for correct disposal and completing daily educational quizzes, which can be tracked via a personal transaction log and traded for digital vouchers.
* **Dynamic Route Optimization:** A simulated logistics engine that generates carbon-efficient routes by skipping empty bins and calculating the shortest path between over-filled bins.
